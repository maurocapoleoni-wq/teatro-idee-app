# Idee

Piccola app web per mandare idee dal telefono alla cartella `inbox/` di un archivio GitHub privato.

- Il codice è pubblico, ma non contiene dati. Le idee finiscono solo nell'archivio privato.
- La chiave GitHub si inserisce nell'app e resta salvata solo nel telefono.
- Non sovrascrive mai un file: se il nome esiste già, ne crea uno nuovo.
- Senza rete l'idea resta in attesa e parte appena torna la connessione.
